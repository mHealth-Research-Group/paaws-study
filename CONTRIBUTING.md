# Contributing to PAAWS Study

Thank you for your interest in the Physical Activity Assessment using Wearable Sensors (PAAWS) Study! This repository serves as the main directory for our dataset, software tools, and related resources.

## About the Project

The PAAWS Study is an NIH-funded research project (R01CA252966) aimed at developing and validating methods for measuring 24-hour physical behavior using wearable devices. For more information, visit [paawsstudy.org](https://paawsstudy.org).

## Ways to Contribute

### Reporting Data Issues

If you encounter issues with the dataset:
- **Data quality concerns** - Report inconsistencies, missing values, or unexpected patterns
- **Documentation errors** - Identify unclear or incorrect documentation
- **Access problems** - Report broken links or download issues

Please open an issue with:
- Clear description of the problem
- Specific file(s) or dataset(s) affected
- Steps to reproduce (if applicable)

### Reporting Software Issues

For issues with provided software tools:
- Describe the bug or unexpected behavior
- Include your environment (OS, Python version, dependencies)
- Provide minimal code to reproduce the issue
- Share relevant error messages

### Suggesting Improvements

We welcome suggestions for:
- Additional documentation or examples
- New features for software tools
- Data format improvements
- Tutorial or usage examples

### Contributing Examples or Analyses

If you've used the PAAWS data in your research:
- Share example analyses or visualization code
- Contribute tutorials showing data usage
- Submit case studies demonstrating methods

## Getting Started

1. **Fork the repository** (for code contributions)
2. **Open an issue** to discuss proposed changes
3. **Submit a pull request** with clear description of changes

## Data Usage Guidelines

When using PAAWS data:
- Review and comply with the data use agreement
- Cite the dataset appropriately in publications
- Acknowledge NIH funding (R01CA252966)

## Questions or Support

For questions about the study, data access, or collaboration opportunities, please visit [paawsstudy.org](https://paawsstudy.org) for contact information.

## Code of Conduct

We are committed to fostering an inclusive and respectful research community. All contributors are expected to:
- Be respectful and professional in all interactions
- Provide constructive feedback
- Focus on what is best for the research community
